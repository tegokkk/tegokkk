## 👨‍💻 About Me

I'm a **Full-Stack Developer** who enjoys turning ideas into working products — from clean, responsive interfaces to solid REST APIs and well-structured relational data models.

- 🔭 Currently building apps around **attendance management, laboratory reservations, food ordering,** and **business websites**
- 🛠️ Main stack: **React / Next.js** on the frontend, **Express, Prisma & PostgreSQL** on the backend
- 🌱 Constantly refining how I design databases, APIs, and developer-friendly codebases
- 💬 Ask me about **JavaScript/TypeScript, full-stack architecture,** or **database design**
- ⚡ Fun fact: I like keeping my projects practical — solving real, everyday problems
